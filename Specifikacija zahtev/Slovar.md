# Dokumentacija - Slovar pojmov

## 1. Uvod 

Za lažje razumevanje dokumentacije je pripravljen slovar pojmov, v katerem so razloženi pomembnejši izrazi, uporabljeni v projektu. Slovar omogoča boljše razumevanje funkcionalnosti sistema in pomaga pri enotni uporabi izrazov skozi celotno dokumentacijo.

## 2. Slovar pojmov

| Pojem | Opis |
|---|---|
| Program lojalnosti | Sistem za nagrajevanje strank glede na njihove nakupe in aktivnost. |
| Uporabnik | Oseba, ki uporablja sistem programa lojalnosti. |
| Član programa | Registriran uporabnik, ki sodeluje v programu lojalnosti. |
| Administrator | Oseba, ki upravlja sistem, pravila, nagrade in točke uporabnikov. |
| Registracija | Postopek ustvarjanja uporabniškega računa v sistemu. |
| Prijava | Postopek preverjanja identitete uporabnika za dostop do sistema. |
| Točke | Enote, ki jih uporabnik pridobi z nakupi ali aktivnostmi v programu. |
| Koriščenje točk | Uporaba zbranih točk za pridobitev nagrad ali ugodnosti. |
| Prepis točk | Ročna sprememba oziroma dodelitev točk uporabniku s strani administratorja. |
| Nagrada | Ugodnost ali izdelek, ki ga uporabnik pridobi z uporabo točk. |
| Status uporabnika | Raven oziroma kategorija uporabnika glede na zbrane točke ali aktivnost. |
| Točkovnik | Pravila za izračun in dodeljevanje točk uporabnikom. |
| Poslovni IS | Poslovni informacijski sistem podjetja, iz katerega sistem pridobiva podatke o nakupih. |
| Integracija | Povezava med sistemom lojalnosti in drugimi informacijskimi sistemi. |
| E-poštni sistem | Sistem za pošiljanje potrditvenih in obvestilnih sporočil uporabnikom. |
| Poštna služba | Zunanja storitev za pošiljanje fizičnih kartic uporabnikom. |
| Mesečni izračun točk | Proces samodejnega izračuna in posodobitve točk uporabnikov. |
| Upravljanje pravil | Spreminjanje pravil programa lojalnosti, statusov in nagrad. |
| Portal za stranke | Del sistema, namenjen uporabnikom za pregled podatkov in koriščenje funkcionalnosti. |
| Validacija e-pošte | Preverjanje pravilnosti in obstoja e-poštnega naslova uporabnika. |
